template<::beman::execution::detail::completion_signature... Signatures>
struct beman::execution::completion_signatures< Signatures >

Class template used to a specify a list of completion signatures.

This class template is primarily used for type computations and objects of any specializaion are empty. Objects may be created to return them from functions used for type computations like get_completion_signatures(sender, env).
